# Code of Conduct

We want Scrybe to be a welcoming, harassment-free project for everyone. This is a short statement inspired by the Contributor Covenant (https://www.contributor-covenant.org); you may replace it with the full text.

**Expected:** be respectful and constructive, assume good faith, give and accept feedback graciously, focus on what is best for the project and community.

**Unacceptable:** harassment, discrimination, personal attacks, doxxing, sexualized language or attention, and other conduct a reasonable person would find inappropriate in a professional setting.

Maintainers may remove, edit or reject contributions and ban participants for violations. Report concerns privately to the maintainer (see LICENSE for contact), who will handle them confidentially.
