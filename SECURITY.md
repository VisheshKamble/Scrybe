# Security policy

Please report vulnerabilities privately via GitHub's "Report a vulnerability" (Security tab) for this repository, or by contacting the maintainer listed in the LICENSE. Do not open public issues for security problems. Include reproduction steps and affected versions; we aim to acknowledge reports promptly and will credit reporters who want it.

Scope notes and known gaps (no auth yet, injection defense is layered not absolute) are documented in [docs/security.md](docs/security.md). Never include real API keys or cookies in reports.
